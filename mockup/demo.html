Emulator

The shipping build is the device core (SDL2 and LVGL) compiled to WebAssembly and drawn to a canvas, with the keypad as real buttons beside it. What runs here is a plain JavaScript stand-in of the same interface, so the layout and the key map can be judged before the WebAssembly port lands. The buttons really work.
